# AI 

## 「AIの答えを評価する力」をUPしたいのであれば

特におすすめなのは、毎日AIに何か聞いたあと、最後に必ずこれを聞く習慣です。

>「この回答を信用すると危険なポイントを3つ挙げて」

<br>

## AI時代の重要な質問テンプレート

### 1. 全体像をつかむ

* この分野を理解するために必要な概念を5個に分けて
* これは何の問題を解決するもの？
* 全体構造を初心者向けに説明して

### 2. 深く理解する

* なぜそうなる？
* 従来の方法ではなぜダメ？
* 内部ではどう動いている？

### 3. 判断する

* AとBなら、どんな条件で使い分ける？
* どんな場合は使わない方がいい？
* この選択のトレードオフは？
* 私の条件なら、どれを選ぶべき？理由も教えて

### 4. AIの回答を疑う

* この回答を信用すると危険なポイントを3つ挙げて
* この回答が間違っている可能性は？
* この回答の前提条件は？
* 抜けている観点は？
* 別の専門家ならどう反論する？

### 5. 自分の理解を検証する

* 私の理解の間違いを指摘して
* 私の説明で抜けている部分は？
* 私の判断を厳しくレビューして
* 重要なのに私が聞いていないことは？

### 6. 失敗を先に知る

* 典型的な失敗パターンは？
* どこで壊れやすい？
* 本番運用すると何が問題になりやすい？
* 最悪のケースは？

---

## 最重要5問

1. これは何の問題を解決する？
2. 判断基準は何？
3. どんな場合は使わない？
4. 私の理解の抜けは何？
5. この回答を信用すると危険な点は何？

---

### 基本の思考順序

**目的 → 構造 → 選択肢 → 判断基準 → リスク**
